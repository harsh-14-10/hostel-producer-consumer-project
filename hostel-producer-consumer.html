Hostel Cleaning Desk

Students post room-cleaning requests onto a fixed-size notice board. Housekeeping staff take them off. Semaphores keep the board from overflowing, being read empty, or being corrupted by two people at once.

    The algorithm

    // Shared: empty = N, full = 0, mutex = 1
Producer (student):
  loop:
    request = writeRequest()
    wait(empty)    // free slot on board?
    wait(mutex)    // lock the board
    board[in] = request
    in = (in + 1) % N
    signal(mutex)
    signal(full)   // one more request
    Consumer (staff):
  loop:
    wait(full)     // any request waiting?
    wait(mutex)    // lock the board
    request = board[out]
    out = (out + 1) % N
    signal(mutex)
    signal(empty)  // one slot freed
    cleanRoom(request)

    Turn semaphores off to watch the three classic failures: overflow (a request overwrites an unread one), underflow (staff find nothing to take) and race conditions (two actors use the same pointer at once).
